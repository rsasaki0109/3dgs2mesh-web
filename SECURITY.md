# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private security advisory flow for this repository, or contact the maintainer through the profile at [github.com/rsasaki0109](https://github.com/rsasaki0109). Include a minimal reproduction and the affected commit when possible.

The application is designed for local-only processing and has no analytics or upload endpoint. Still, treat untrusted PLY files as untrusted input and keep your browser current.
